# LastDatabase for Gemini CLI

Official LastDatabase MCP extension for Gemini CLI.

## Installation

Install from GitHub:

    gemini extensions install https://github.com/lastdatabaseph/lastdatabase-gemini

## Authentication

Start Gemini CLI and run:

    /mcp auth lastdatabase

Then verify the connection:

    /mcp list

## Available Tools

- get_credits
- search_people
- search_consumer_emails
- search_hot_leads
- search_mixed_leads
- search_phone_leads
- unlock_people
- verify_email
